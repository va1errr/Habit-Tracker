# US-004 - Update Habit

## Related User Story

[US-004 - Изменение привычки](../user-stories/US-004-update-habit.md)

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/habits/{id}`

## Path Parameters

- `id` - ID существующей привычки (`integer (int64)`)

## Request

### Headers

| Header         | Value              | Required |
|----------------|--------------------|----------|
| `Content-Type` | `application/json` | yes      |

### Body

```json
{
  "name": "string",
  "description": "string"
}
```

### Request Fields

| Field         | Type             | Required | Validation                                                                       |
|---------------|------------------|----------|----------------------------------------------------------------------------------|
| `name`        | `string`         | yes      | После удаления пробелов в начале и конце не должно быть пустым                   |
| `description` | `string \| null` | no       | Поле отсутствует — сохранить прежнее описание; null — удалить; строка — заменить |

## Successful Response

### Status

`200 OK`

### Body

```json
{
  "id": 1,
  "name": "string",
  "description": "string",
  "active": true
}
```

### Response Fields

| Field         | Type             | Description                                                            |
|---------------|------------------|------------------------------------------------------------------------|
| `id`          | `integer`        | ID обновлённой привычки                                                |
| `name`        | `string`         | Название обновлённой привычки                                          |
| `description` | `string \| null` | Описание обновлённой привычки или `null`, если у привычки нет описания |
| `active`      | `boolean`        | Активна ли обновлённая привычка                                        |

## Error Responses

| Situation                                                               | Status            |
|-------------------------------------------------------------------------|-------------------|
| `Название отсутствует, имеет значение null или является пустой строкой` | `400 Bad Request` |
| `Название состоит только из пробельных символов`                        | `400 Bad Request` |
| `Некорректный id (невозможно преобразовать в 64-битное целое число)`    | `400 Bad Request` |
| `Привычка с данным id не найдена`                                       | `404 Not Found`   |
| `Привычка с данным id архивирована`                                     | `404 Not Found`   |
| `Название уже существует`                                               | `409 Conflict`    |

### Error Body

```json
{
  "status": 400,
  "message": "string",
  "errors": [
    {
      "field": "string",
      "message": "string"
    }
  ]
}
```

### Error Fields

| Field            | Type      | Description                                 |
|------------------|-----------|---------------------------------------------|
| `status`         | `integer` | HTTP статус ошибки                          |
| `message`        | `string`  | Короткое сообщение об ошибке                |
| `errors`         | `array`   | Массив с деталями ошибки, может быть пустым |
| `errors.field`   | `string`  | Поле, в котором ошибка                      |
| `errors.message` | `string`  | Описание ошибки в поле                      |

## Business Rules

- Название привычки обязательно
- Названия не чувствительны к регистру. При получении названия API удаляет все пробельные символы в начале и конце строки
- Текущая привычка исключается из проверки, поэтому прежнее имя и изменение только регистра разрешены
- Описание привычки необязательно
- Архивированную привычку нельзя изменить
