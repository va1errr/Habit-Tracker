# US-005 - Archive Habit

## Related User Story

[US-005 - Архивирование привычки](../user-stories/US-005-archive-habit.md)

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/habits/{id}`

## Request

### Path Parameters

- `id` - ID привычки (`integer (int64)`)

## Successful Response

### Status

`204 No Content`

### Body

Отсутствует.

## Error Responses

| Situation                                                            | Status            |
|----------------------------------------------------------------------|-------------------|
| `Привычка с данным id не найдена`                                    | `404 Not Found`   |
| `Привычка с данным id архивирована`                                  | `404 Not Found`   |
| `Некорректный id (невозможно преобразовать в 64-битное целое число)` | `400 Bad Request` |

### Error Body

```json
{
  "status": 400,
  "message": "string",
  "errors": [
    {
      "field": "string",
      "message": "string"
    }
  ]
}
```

### Error Fields

| Field            | Type      | Description                                 |
|------------------|-----------|---------------------------------------------|
| `status`         | `integer` | HTTP статус ошибки                          |
| `message`        | `string`  | Короткое сообщение об ошибке                |
| `errors`         | `array`   | Массив с деталями ошибки, может быть пустым |
| `errors.field`   | `string`  | Поле, в котором ошибка                      |
| `errors.message` | `string`  | Описание ошибки в поле                      |

## Business Rules

- Удаление привычки означает архивирование, то есть soft delete
- Архивирование привычки не удаляет сохранённые факты выполнения
- Архивированная привычка не видна в общем списке, ее нельзя выполнить
- API отвечает 404 на получение архивированной привычки
- Архивированную привычку нельзя изменить
- Архивированную привычку нельзя отметить выполненной или отменить её выполнение
- Имя архивированной привычки остается занятым
